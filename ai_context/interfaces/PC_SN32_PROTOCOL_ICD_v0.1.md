# FPGA MCU Trinity — PC↔SN32 Protocol ICD

**Status:** `APPROVED IMPLEMENTATION BASELINE`  
**Version:** `v0.1`

UART is 115200 8N1. Raw binary frame is COBS encoded and terminated by `0x00`.

```text
0       VERSION = 0x01
1       COMMAND
2       FLAGS
3       RESERVED = 0
4..5    TRANSACTION_ID, big-endian
6..7    PAYLOAD_LENGTH, big-endian
8..     PAYLOAD, maximum 256 bytes
last 2  CRC-16/CCITT-FALSE, big-endian
```

Events use command `0xE0`, `EVENT` flag and transaction ID `0`. Every response or
event payload must remain ≤256 bytes.

## MODE

```text
0x00 KAT
0x01 DEMO_DETERMINISTIC
0x02 DEMO_SECURE
```

`DEMO_SECURE` returns `0x0702 NOT_SUPPORTED` until O-002 closes.

All previously approved request/response layouts remain normative. Additional
rules:

- `READ_LAST_RESULT` with no valid result returns `0x0304 RESULT_NOT_READY`;
- `GET_TXN_RESULT` and `RETIRE_TXN_RESULT` are idempotent;
- reconnect uses status and transaction reconciliation;
- progress events do not replace final responses;
- event transaction ID is always 0;
- secret material is never written to default JSON evidence.

Initial timeout classes remain 500 ms, 2 s, 5 s, 20 s and 120 s by approved
command class. They may change only through evidence-backed amendment.
