# Detailed baseline context

These files preserve the full requirement and decision detail that preceded the
controlled source gate. They are part of active project memory for functional
requirements, architecture rationale, state-machine behavior, verification and
acceptance detail.

Authority rule:

1. Current compact System Spec and Decision Register control document status,
   current open-item state and implementation authorization.
2. Current approved ICDs and `PROTOCOL_REGISTRY_v0.1.json` control byte values,
   enums and wire behavior.
3. Detailed files in this directory supply omitted requirement/rationale detail.
4. Any old preamble saying `SOURCE NOT STARTED`, or listing O-012/O-013/O-014/
   O-015 as blockers, is superseded by A-028 through A-032 in the current
   Decision Register.
5. Functional content remains active unless a newer identified decision or ICD
   explicitly overrides it.

This precedence prevents the detailed memory from creating a competing status or
wire contract.
